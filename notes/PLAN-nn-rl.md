# NN/RL 训练线 —— 分阶段计划（含 M 线负结果驱动的修正）

## 0. 硬证据（决定架构）

### M 线：整段替换出牌决策 → 显著更差

口径：`scripts/run_ab.py`，treatment = MLP 价值决策器（29 维 → (64,64) → 1，
40 epoch 早停，valid MSE 121.39），baseline = `heuristic`（默认档 v2），
四座位旋转、配对同牌、种子 20260928、20 场 × 8 局 = 80 配对。

| 指标 | 均值 | t | 判读 |
|---|---|---|---|
| 名次分 | −3.425 | −6.67 | 显著更差 |
| 胡次数 | −1.038 | −7.21 | 显著更差 |
| 总得分 | −22.387 | −4.03 | 显著更差 |
| 番数总和 | −0.988 | −3.84 | 显著更差 |

**结论（架构级约束）**：学习模型**不得**整段替换决策。启发式里的结构性知识
（精确进张次排序 / 喂牌代价 / 财神罚 / 吃碰闸门）在 2.5 万样本上无法被小网络复现。

## 1. 三个"不需要"（避免走弯路）

1. **不需要学"玩法规则"**：规则引擎给合法动作掩码，非法项不进候选。
2. **不用真机事件流做训练**：只 ~2400 局，且只含 heuristic 自身动作 → 模仿上限 = 现有策略。
3. **不在随机初始化上直接 RL**：冷启动会重演 M 线结局。

真机事件流的正确用途 = **校准**（验证模拟器分布与真机一致），不是训练。

## 2. 三段式

### 阶段 0：模拟器内行为克隆（warm start）

- 教师 = 主仓库 `heuristic`（默认档 v2），学生 = 候选排序网络。
- 数据来自**自对弈模拟器**（无限、零平台请求），标签 = 教师在同一局面的选择。
- **门禁（硬性）**：学生必须在 held-out 局面上达到与教师足够高的 top-1 一致率。
  达不到 ⇒ 架构不对，**停在这步，不进 RL**（省下后续全部算力）。
- 这一步本身没有增益期望，**它的唯一价值是得到一个不比教师差太多的起点**。

### 阶段 1：自对弈 RL 微调（**增量式，不整段替换**）

- **动作表示**：不逐张打分（M 线已证死），改为**在启发式候选集上排序/加权**：
  网络输出对启发式给出的 top-k 候选的修正分，启发式的分数作为基线特征。
- **对手池**：不只用三个自己的复制品（主仓库实测：默认场地对任何偏离都给正分，
  符号不可信）。用**历史版本池 + 现有各实验档位**混合成异质场地。
- **判据**：名次分 / 胡次数（低方差），并报**跨种子分布**；单种子不作数。
- kill criteria：若跨种子名次分不显著为正，线终止，不改默认档。

### 阶段 2：并入参赛运行路径（仅在阶段 1 显著为正时）

- 产物转**纯 Python 前向**（已具备：`model.json` + `pure_forward`，与 torch 差 9.5e-07）。
- 由**人**决定是否改默认档（主仓库 PROTOCOL §6）。

## 3. 算力纪律

- 离线重活 `nice -n 15`，**同一时刻只跑一个**（主仓库 PROTOCOL §5.4）。
- 守护循环抗环境周期性回收（`scripts/supervise.sh`）。
- 显存上限硬约束（`set_per_process_memory_fraction`）。
