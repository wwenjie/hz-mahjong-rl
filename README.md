# 杭州麻将 AI — NN / RL / MLP 研究线（独立仓库）

本仓库是参赛程序主仓库 [`hz-mahjong-ai`](https://github.com/wwenjie/hz-mahjong-ai)
（WSL2 路径 `/home/wuwenjie01/majiang_ai`）**之外**的独立研究仓库。

> **一句话边界：主仓库只读，本仓库全权。**

## 一、为什么独立

主仓库已有三名成员（A 策略主线 / B 独立验证 / C 本地部署与值守）在同一棵树上工作，
其 `notes/OWNERSHIP.md` 的第一条铁律是「任何时刻同一文件只有一个所有人」。
NN/RL/MLP 研究线若直接进主仓库，必然与 C 的 `research/**` 所有权冲突。

因此本线**另起一仓**：

| | 主仓库 `hz-mahjong-ai` | 本仓库 `majiang-nnrl` |
|---|---|---|
| 关系 | **只读**（消费其公开数据） | 全权所有 |
| 写入 | **禁止**（代码层强制） | 自由 |
| 成员 | A / B / C | Chief of Staff（NN/RL 线） |

## 二、只读桥

所有对主仓库的访问都经过 `src/nnrl/paths.py`：

- 主仓库根由环境变量 `MAJIANG_REPO` 指定，默认 `/home/wuwenjie01/majiang_ai`。
- 只暴露 `data/` 下的**读取**入口（离线数据分片、事件流）。
- 任何指向主仓库的写入尝试都会被 `forbid_write()` 拒绝。
- `tests/test_paths.py` 固化这条边界。

```bash
export MAJIANG_REPO=/home/wuwenjie01/majiang_ai   # 可选，默认即此
```

## 三、主线原则（继承主仓库的纪律，不重蹈其六次翻车）

1. **四座位旋转**：任何策略对比必须旋转座位；固定座位会测出假优势。
2. **按房分层抽样**：不以文件为抽样单位（一个房四家固定）。
3. **多种子复核**：单种子会给反向结论；报跨种子分布。
4. **参数对等**：比较表示/结构时，对照臂的参数预算必须对齐。
5. **先对仪表**：任何指标用于决策前，先在**已知答案的小样本**上验一次；
   复现必须先与原始记录对齐。
6. **低方差判据**：用名次分 / 胡次数 / 胜率，不用重尾的每手分。
7. **显存预算**：单次训练不超过本机 GPU 上限（8GB 级），支持检查点续跑。
8. **不碰平台**：本线**零平台请求**；主仓库的采集进程与其令牌一概不碰。
9. **不挤算力**：离线重活 `nice -n 15`，且同一时刻只跑一个。

## 四、验收口径（本线的"完成"定义）

- 每个结论附：样本量、口径（含听牌率等易混口径的说明）、噪声底、跨种子分布。
- 新模型与基线**同一批样本对拍**；未超噪声底 = 「无显著增益」，归档备查，不改任何默认。
- 产物若要进参赛运行路径，必须是**纯 Python 可推理**（主仓库 `src/majiang/**` 零第三方依赖）。
  是否进运行路径由**人**决定，本仓库不擅自推动。
